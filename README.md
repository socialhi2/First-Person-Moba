# First-Person-Moba
I want to create a game similar to the chinese anime King's Avatar but in first person. This is a long stretch, and I am not the best at coding but it's my goal to make it reality.
Much like many computer science students, I liked working on computers since the beginning which is why I chose the field but after going to college, I learned that they really did not teach you anything besides how to communicate. Some teachers actually taught how to code, but most never do. Using this project will just be a big steppingstone in that area. 

# Setting
You are an aspiring adventurer and have started your journey in ** Town X **. This town is a simple town where you learn basic player controls and about the game.

## Design Goals
Player movement is fluid
Low skill floor with extremely high skill ceiling
Advanced combat system (Where melee weapon swings need players to rotate model to increase radius similar to chivalry 2)
Fantasy environment similar to Isekai genre
Fast paced combat
